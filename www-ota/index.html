Nightscout Clock, version OTA

Premier flash par USB de la version avec mises à jour Wi-Fi, en gardant les réglages de l'horloge. Release disponible : …

Ce navigateur ne gère pas Web Serial. Ouvre cette page dans Chrome ou Edge sur un ordinateur.

1. Brancher l'horloge

Branche l'horloge en USB, clique sur le bouton et choisis son port série (USB-SERIAL CH340). La page lit ses réglages sans rien modifier ; la lecture prend environ une minute et demie.

2. Vérifier les réglages

Pas encore lus.

Télécharger une copie des réglages

3. Installer

Écrit la table de partitions, le firmware et l'interface web, puis redémarre l'horloge. Ses réglages sont recopiés au premier démarrage.

Ensuite, les mises à jour se font depuis la page de l'horloge : WiFi & system > Update over WiFi.
